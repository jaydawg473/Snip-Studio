RECOGNIZED REGIONS AND COLUMN NAVIGATION
Strong graphic prefixes are separated from an OCR edit run before font/color
estimation and background erasure. Conservative graphic/column anchors help
keep icons separate from editable words. Ambiguous source symbols are retained.
Fresh clicks and reentry into previously edited notes keep neighboring columns
separate, including older notes whose original frame extends over another cell.

The region processor and hit testing changed; the global font matcher and
Windows OCR engine were not replaced. OCR spelling, source-font identity,
mixed formatting and raster reconstruction remain approximate. Untouched source
pixels and existing edit/Undo safeguards remain important when reviewing edits.

TEXT COLOR AND PALETTE VIEW
Chosen text color applies from the first character of a new point/drawn note.
The text swatch follows the active rich-text selection or caret, describes mixed
colors, and updates when a color is applied. Source-text editing retains its
current formatting until explicitly changed. Drawing ink remains a separate
choice. These tests do not prove the accuracy of sampled source-color estimates.

Palette transitions keep window/client bounds fixed. Fit recalculates for the
available image viewport, keeps the full snip centered/contained, and clears
stale native scroll extents on open/close. Manual zoom remains fixed and its
center anchor is checked within one rendered viewport pixel while open; closing
restores the original zoom, absolute origin and scroll extent. The palette keeps
its own preferred content size and scrolling. This is view stability within the
existing window, not a new automatic window-resizing policy.

RETAINED FEATURES AND NOTICES
Recording-area choices, desktop boundary, MP4 filmstrip/trim and the external
Clipchamp action remain. Window recording uses a fixed visible screen rectangle,
including other covering windows; it does not follow a moving target or recover
hidden content. Inset boundary segments require supported Windows exclusion.
Prior hidden-native readback did not establish saved-video pixel exclusion.

The original filmstrip implementation uses Windows Media Foundation. Microsoft's
VideoThumbnail sample was a technical reference; its full pinned MIT credit
remains in licenses/NOTICES.txt. Existing notices, artwork and translation files
are retained and reconciled by the package audit.

LIMITATIONS AND DELIVERY
Unshown controls, synthetic recognition/seeded formatting and managed gestures
are not physical mouse/focus/DPI tests or pixel-perfect font recovery. Private
supplied images and diagnostic reports are excluded from public source, assets
and release payloads. No live recording/exclusion, external Clipchamp import or
installed upgrade is established by these text-region checks.

Exact Setup/ZIP hashes, fresh signatures/timestamps, extracted payload identity,
NSIS CRC/protected-byte checks and privacy-marker results belong to the separate
local release receipt. Container hashes are not embedded in this payload file.
Known-marker checks are not a universal privacy guarantee. Installation and Git
publication are not performed by this validation; publication remains paused.
