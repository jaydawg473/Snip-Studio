PERFORMANCE
A 3,600-word, 60-pointer-sample selection trace allocated 289,760 bytes versus
16,066,424 bytes on the signed baseline: 98.2% fewer measured allocations,
with zero rather than two Gen0 collections. Final observed trace time was 13 ms.
Repeated native font refinement measured under 1 ms stopwatch resolution after
warming. Initial refinement is still costly; shared-machine contention affects
latency. Native OCR speed is not claimed as improved.

For synthetic 24 MP images, the earlier signed candidate's snapshot render took
85-86 ms; encoding took 158-1,412 ms for PNG and 327-2,503 ms for PDF. Those
single-run codec measurements are not a throughput improvement claim. The save
change moves encoding/publishing off the UI thread. Snapshot rendering remains
on the UI thread, and forced teardown may wait for the safe worker to finish.
Full application startup, live scrolling latency, microphone/system audio,
recording throughput and long-session memory have not been measured here.
