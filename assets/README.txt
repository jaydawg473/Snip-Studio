SNIP STUDIO ICON SET

36 original toolbar symbols, designed on a 24-unit grid with rounded 1.8-unit strokes.
SVG files use currentColor so an app or stylesheet can choose the ink color.
PNG files use pale blue-white ink for the dark Snip Studio workspace.
SnipStudio.ico contains 16/24/32/48/64/128/256-pixel PNG-compressed frames.
The app mark is also supplied as vector SVG and transparent 256/512-pixel PNG.

All live toolbar images and exported symbols share IconArtwork.cs geometry.
Run tools\BuildIcons.exe assets to regenerate these files after compiling
tools\BuildIcons.cs together with IconArtwork.cs and System.Drawing.
