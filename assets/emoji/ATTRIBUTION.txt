catalog keys. The default yellow variants are used for the five hand/arm
stickers. No PNG pixels were changed. Rendering uses each PNG's nontransparent
source bounds, preserving aspect ratio without altering the bundled files.

SHA-256, file size, dimensions, and nontransparent bounds. The revision is a
pinned Git commit, not a claimed upstream release number. No fonts, paid API,
or runtime network download are used by the emoji artwork renderer.
