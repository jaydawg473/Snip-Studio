# Snip Studio 0.6.24

Automation Forge

The editor now gives unused toolbar space back to the canvas. Previously it always reserved the combined height of the largest text panels, leaving an oversized top gap even when tool options were closed or a smaller Highlight row was open.

The image viewport starts below the controls actually visible. Preferred window sizing still allows room for larger tools. Fit adapts to the available viewport; manual zoom and pan retain their view intent.

The OCR, editing, save, metadata, recording recovery and signed runtime changes from 0.6.23 remain. Detailed signed verification and remaining native/installed acceptance are recorded in `VALIDATION.txt`.

Installer: `SnipStudio-0.6.24-Setup.exe`. Portable: extract every file from `SnipStudio-0.6.24-signed-portable.zip` together before running `Snip Studio.exe`. Installation and a public GitHub Release remain pending approval.
