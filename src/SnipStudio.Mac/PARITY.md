# Snip Studio macOS feature parity

This checklist compares Windows 0.7.0 (`c41c21e98dfcbd2f342a2069c62bd77fb0fd49d9`) with the Mac trial in this checkout. **In source** records an implemented Mac workflow. **Partial** identifies the portion built so far. **Pending** identifies a workflow that still needs implementation. These states describe source inspection. Record signed-device results separately.

The Mac target is macOS 14 or later on Apple Silicon. [Windows 0.7.0 release notes](https://github.com/jaydawg473/Snip-Studio/blob/c41c21e98dfcbd2f342a2069c62bd77fb0fd49d9/release-notes-0.7.0.md) · [Main window](https://github.com/jaydawg473/Snip-Studio/blob/c41c21e98dfcbd2f342a2069c62bd77fb0fd49d9/src/SnipStudio.WinUI/MainWindow.xaml) · [Recording window](https://github.com/jaydawg473/Snip-Studio/blob/c41c21e98dfcbd2f342a2069c62bd77fb0fd49d9/src/SnipStudio.WinUI/RecordingWindow.xaml) · [Settings view](https://github.com/jaydawg473/Snip-Studio/blob/c41c21e98dfcbd2f342a2069c62bd77fb0fd49d9/src/SnipStudio.WinUI/DesktopSettingsView.cs)

## Feature checklist

| Windows 0.7.0 workflow | Mac status | Native acceptance |
| --- | --- | --- |
| New, screenshot mode, rectangle and window capture, delay | In source. New, mode and delay use the Windows toolbar order. | Grant and deny capture permission. Capture a region and a window with Off and with a delay. Cancel each selector and check that the working snip remains. |
| Current monitor, all monitors, freeform | Partial. Primary-screen, all-monitor and freeform capture on a selectable display are wired. Fullscreen capture of a specific secondary display remains pending. | Arrange Retina and non-Retina screens above and beside each other. Check orientation, scale, mirroring, empty gaps, bounds and omission of Snip Studio. Check freeform transparency and cancellation. |
| Scrolling capture, partial review, stitch joins | Partial. Manual scroll-and-sample capture, overlap validation, and review of accepted views are in source. Automatic scrolling and displayed join guides remain pending. | Capture a long page with sticky headers and changing content. Inspect the final stitch and test keeping and discarding a partial result. |
| Automatic clipboard copy and saving the original capture | In source. Both settings default to on. | Paste immediately after capturing, erasing and Undo. Check newest-operation precedence, disabled automatic copy and preservation of the original in Pictures/Snip Studio. |
| Compact launcher, editor toolbar, contextual options and status footer | In source. The launcher, toolbar rows, canvas and footer follow the Windows reference. | Compare the empty launcher, first snip, pen, highlighter and Text Actions in light and dark appearances at narrow and normal widths. Check focus, labels and readable hit targets. |
| Pen and Highlighter with color, width and preview | Partial. Pen and freehand highlighter are in source. Text snapping, reusable colors, opacity controls and eyedropper remain pending. | Compare exported ink and the stroke preview on black and white backgrounds. Check that pen and highlighter preferences stay independent and snap only when enabled. |
| Shapes, emoji stickers, line styles and opacity | Partial. Rectangle, ellipse, line and arrow with solid, dashed and dotted outlines are in source. Fill, opacity controls and emoji remain pending. | Draw all four shapes, including arrowheads during the drag. Check fill, outline, opacity, solid/dashed/dotted lines and emoji placement after copy and export. |
| Move, resize, rotate and change object properties | Partial. Select-and-drag movement, 90° rotation, color, opacity, width and line-style changes are in source. Resize handles and direct hover-to-move from other tools remain pending. | Hover and drag an object by its edge, resize and rotate, adjust style afterward, then verify precise Undo and Redo. |
| Erase annotations, crop and remove image areas | In source. Annotation eraser, erase all, crop with handles, and rectangular source-area removal support Undo and Redo. | Erase the topmost annotation on overlap. Test erase all, crop edge handles, Apply, Escape, transparent removal and Undo/Redo for each operation. |
| Editable on-canvas text | Partial. Native inline editing with font presets, independent pixel size, color, bold, italic and underline is in source. Advanced formatting and color emoji are pending. | Add and reopen multiline text. Verify font, pixel size, foreground color, bold, italic, underline and advanced properties. Check Done and Cancel without height drift or clipped lines. |
| Undo/Redo and unsaved-document protection | In source for strokes. Close, quit and replacement consult the saved revision. | Repeat Undo/Redo, branch after Undo, close a new capture and try Quit with Cancel and Discard. Save an older snapshot while editing and ensure later edits remain unsaved. |
| Fit, zoom presets, pan, full screen and resize to snip | Partial. Fit, actual-size and zoom presets with trackpad/scrollbar panning are in source. Pointer-drag pan, custom zoom, the Windows-style full-screen action and automatic resize-to-snip remain pending. | At 100% on Retina check the one-source-pixel scale. At high zoom, verify both axes and ink placement after pan. Check small-snips and manually resized windows. |
| Text Actions and basic local OCR | Partial. Vision recognition, row ordering, text-region overlay, review and copy-all are in source. Windows row rereads and accuracy parity are unverified. | Compare seven ordered text lines including dense filenames, duplicate rows, a device path, leading zeros and distracting icons. Use both light and dark snips and compare original OCR output. |
| OCR word/row selection, copy selection, copy as table, edit and conversion | Partial. On-image selection and clipboard actions use Vision observations. Word-level selection within a merged observation, text editing and batch conversion remain pending. | Select across columns, paste into a spreadsheet and assert rows and cells. Convert with Text selected, editable source-style notes, retained originals and matching position. |
| Quick redact, delete recognized content and review before sharing | In source. Quick redact previews email and phone regions and writes approved opaque rectangles. Delete can remove selected OCR regions from the source pixels. | Review email and phone proposals and reject false matches. Verify redaction and deletion in clipboard and file exports, including after Undo and Redo. |
| Local or explicitly configured HTTPS translation | Pending. | Compare source and translation side by side. Apply reviewed rows without changing identifiers, leading zeros, layout or source content outside the selected area. Check offline use and cancel behavior. |
| Screen recording controls and audio | Partial. Requires macOS 15 or later. Compact controls include source choice, display-region preview, system audio, microphone and Stop. Window recording captures full bounds. Audio device selection, adjustable window bounds and an on-screen boundary remain pending. | Select a display region or window, check the preview and adjust the display region before starting. Verify separate microphone and system audio, pointer setting, timer, reachable Stop, exclusion of recorder controls, cancellation and the completed MP4. |
| Video review, filmstrip, trim and export | In source for opened video. The filmstrip, trim, export and playback controls outside the image are in source. | Open a video and review the recording. Scrub, seek with keyboard, select trim handles, preview range, check playback controls stay off the image, and independently validate saved MP4 and audio. |
| Compress for email, copy video, external video editing | Partial. Size-limited MP4 export and video clipboard copy are in source. External editor handoff remains pending. | Validate requested size with measured output bytes, usable audio and video, file clipboard behavior and the editor handoff supported on macOS. |
| Open/Paste, clipboard, Save As and editable snip projects | In source for Mac projects. Open, paste, clipboard and atomic PNG, JPEG, BMP and PDF exports are in source. `.snipstudiomac` stores editable annotations and original image pixels. Windows `.snipstudio` interoperability remains pending. | Open and paste an image. Reopen exports with an independent viewer, check dimensions and transparency, reopen a project with annotations, and test canceled or failed writes. |
| Share, print, and external image editor | In source. Native Print, Share, and a durable working-copy and import workflow use the rendered revision. | Share the composed image, print to a PDF preview and open a working copy in an installed editor. Import changes without overwriting the source. |
| Multiple editors, close all without saving, and recent files | In source. New captures open in separate editors. Close All confirms once. The file menu lists recent images and videos. | Keep an existing snip open while taking a new one, check independent history and current clipboard, then close all with one confirmation. Reopen recent snips and locate recording and screenshot folders. |
| Settings, shortcuts, startup and tray actions | Partial. First three settings persist. macOS shortcuts are wired for New, Open, Paste and Save. Recovery, global shortcuts, launch at login and a menu-bar equivalent remain pending. | Test shortcuts with focus in each editor and dialog. Restart to check settings and ensure unavailable permissions or devices have a clear fallback. |
| Help, original-repo update check, and signed install or upgrade | Partial. The file menu links to Help and checks the original repository for a compatible Mac disk image. The protected signing and notarization workflow is in source. | Install and upgrade the exact Developer ID-signed, notarized DMG on a clean Mac profile. Check Gatekeeper, retained settings and the original repository’s Mac download link. |

## Release verification

- Keep **build**, **signed smoke checks**, and **native interactive checks** in separate records. Match every result to the source revision and disk-image SHA-256.
- Run synthetic checks for OCR reading order and geometry, full-resolution PNG export, stroke history and saved-revision handling from the signed bundle before packaging.
- Use synthetic or sanitized screenshots and recordings on the Mac. Record macOS version, display scaling, permissions and available audio devices with the results.
- Exercise the menu, toolbar and keyboard paths and compare screenshots for each editor state. Verify cancel and failure paths preserve the prior snip and leave the controls usable.
