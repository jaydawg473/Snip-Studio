# Snip Desk feature parity with Snip Studio for Windows

This checklist compares Windows 0.7.0 (`c41c21e98dfcbd2f342a2069c62bd77fb0fd49d9`) with the Mac trial in this checkout. **In source** records an implemented Mac workflow. **Partial** identifies the portion built so far. **Pending** identifies a workflow that still needs implementation. These states describe source inspection. Record signed-device results separately.

The Mac target is macOS 14 or later on Apple Silicon. [Windows 0.7.0 release notes](https://github.com/jaydawg473/Snip-Studio/blob/c41c21e98dfcbd2f342a2069c62bd77fb0fd49d9/release-notes-0.7.0.md) · [Main window](https://github.com/jaydawg473/Snip-Studio/blob/c41c21e98dfcbd2f342a2069c62bd77fb0fd49d9/src/SnipStudio.WinUI/MainWindow.xaml) · [Recording window](https://github.com/jaydawg473/Snip-Studio/blob/c41c21e98dfcbd2f342a2069c62bd77fb0fd49d9/src/SnipStudio.WinUI/RecordingWindow.xaml) · [Settings view](https://github.com/jaydawg473/Snip-Studio/blob/c41c21e98dfcbd2f342a2069c62bd77fb0fd49d9/src/SnipStudio.WinUI/DesktopSettingsView.cs)

## Feature checklist

| Windows 0.7.0 workflow | Mac status | Native acceptance |
| --- | --- | --- |
| New, screenshot mode, rectangle and window capture, delay | In source. New, mode and delay use the Windows toolbar order. | Grant and deny capture permission. Capture a region and a window with Off and with a delay. Cancel each selector and check that the working snip remains. |
| Current monitor, all monitors, freeform | In source. Primary-screen, all-monitor, and selectable full-display or freeform capture are available. | Arrange Retina and non-Retina screens above and beside each other. Check orientation, scale, mirroring, empty gaps, bounds and omission of Snip Desk. Check freeform transparency and cancellation. |
| Scrolling capture, partial review, stitch joins | In source. Start Auto Scroll explicitly and bring the selected source window forward, or capture views manually. Accepted views survive overlap and size errors. Optional stitch guides default off and stay out of exported pixels. | Capture a long page with sticky headers and changing content, with permission granted and denied. Inspect the stitch and test manual capture, stopping and partial review. |
| Automatic clipboard copy and saving the original capture | In source. Clipboard copy defaults on. Saving original captures is opt-in, matching Windows 0.7.0. | Paste immediately after capturing, erasing and Undo. Check newest-operation precedence, disabled automatic copy and preservation of the original in Pictures/Snip Studio after opting in. |
| Compact launcher, editor toolbar, contextual options and status footer | In source. The launcher, toolbar rows, canvas and footer follow the Windows reference. | Compare the empty launcher, first snip, pen, highlighter and Text Actions in light and dark appearances at narrow and normal widths. Check focus, labels and readable hit targets. |
| Pen and Highlighter with color, width and preview | In source. Independent pen and highlighter controls include color, widths, a live example, presets and a system eyedropper. Highlighter has opacity and Vision word snapping, with a Shift freehand override. | Compare exported ink and the stroke preview on black and white backgrounds. Check that pen and highlighter preferences stay independent and snap only when enabled. |
| Shapes, emoji stickers, line styles and opacity | In source. Four shapes, three outline styles, outline and fill opacity, and the Windows sticker catalog use native rendering. | Draw all four shapes, including arrowheads during the drag. Check fill, outline, opacity, solid/dashed/dotted lines and emoji placement after copy and export. |
| Move, resize, rotate and change object properties | In source. Edge hover and drag, corner resize handles, 90° rotation, and style adjustments are editable. Newly placed shapes and stickers select their object controls. | Hover and drag an object by its edge, resize and rotate, adjust style afterward, then verify precise Undo and Redo. |
| Erase annotations, crop and remove image areas | In source. Annotation eraser, erase all, crop with handles, and rectangular source-area removal support Undo and Redo. | Erase the topmost annotation on overlap. Test erase all, crop edge handles, Apply, Escape, transparent removal and Undo/Redo for each operation. |
| Editable on-canvas text | Partial. Native inline editing with font presets, independent pixel size, color, bold, italic and underline is in source. Advanced formatting and color emoji are pending. | Add and reopen multiline text. Verify font, pixel size, foreground color, bold, italic, underline and advanced properties. Check Done and Cancel without height drift or clipped lines. |
| Undo/Redo and unsaved-document protection | In source for strokes. Close, quit and replacement consult the saved revision. | Repeat Undo/Redo, branch after Undo, close a new capture and try Quit with Cancel and Discard. Save an older snapshot while editing and ensure later edits remain unsaved. |
| Fit, zoom presets, pan, full screen and resize to snip | In source. Fit, actual-size, presets and custom zoom, macOS full screen, Retina-aware resize-to-snip, and trackpad or scrollbar panning are available. macOS 15 also supports pointer-drag panning from blank canvas. | At 100% on Retina check the one-source-pixel scale. At high zoom, verify both axes and ink placement after pan. Check small-snips and manually resized windows. |
| Text Actions and basic local OCR | Partial. Vision recognition, row ordering, text-region overlay, review and copy-all are in source. Windows row rereads and accuracy parity are unverified. | Compare seven ordered text lines including dense filenames, duplicate rows, a device path, leading zeros and distracting icons. Use both light and dark snips and compare original OCR output. |
| OCR word/row selection, copy selection, copy as table, edit and conversion | In source. On-image selection retains original recognized text and spacing. If Vision supplies only some word positions, selection uses the full line. Single-line review and selection conversion use sampled colors and approximate fonts on suitable backgrounds. | Select across columns, paste into a spreadsheet and assert rows and cells. Check a line with partial word geometry. Convert with Text selected, editable source-style notes, retained originals and matching position. |
| Quick redact, delete recognized content and review before sharing | In source. Quick Redact scans the visible snip, freezes the review, then writes approved opaque rectangles into a flattened raster. Undo restores editable annotations. Delete can remove selected OCR regions from the source pixels. | Review email and phone proposals and reject false matches. Verify redaction and deletion in clipboard and file exports, including after Undo and Redo and with an email added in an annotation. |
| Local or explicitly configured HTTPS translation | In source on macOS 15 or later. Apple Translation is available on the Mac. An optional LibreTranslate server requires confirmation before sending eligible text. Both use side-by-side review and retain protected identifiers. | Compare source and translation side by side. Apply reviewed rows without changing identifiers, leading zeros, layout or source content outside the selected area. Check offline use, HTTPS test-server responses and cancel behavior. |
| Screen recording controls and audio | In source on macOS 15 or later. Floating controls include display and eligible single-display window crops, system audio, microphone choice, fixed-region border and Stop. System audio follows macOS output. | Select a display region or window, check the preview and adjust the area before starting. Verify separate microphone and system audio, pointer setting, timer, reachable Stop, exclusion of recorder controls, cancellation and the completed MP4. |
| Video review, filmstrip, trim and export | In source for opened video. The filmstrip, trim, export and playback controls outside the image are in source. | Open a video and review the recording. Scrub, seek with keyboard, select trim handles, preview range, check playback controls stay off the image, and independently validate saved MP4 and audio. |
| Compress for email, copy video, external video editing | In source. Size-limited MP4 export, video clipboard copy, and separate working copies for selected local video editors are implemented. | Validate requested size with measured output bytes, usable audio and video, file clipboard behavior and the editor handoff supported on macOS. |
| Open/Paste, clipboard, Save As and editable snip projects | Partial. Read-only Windows `.snipstudio` import preserves strokes, shapes, catalog stickers, grouped highlights, and supported single-style text notes as editable objects. Supported source-text masks are permanently applied to the Mac copy's pixels. Mixed styles, missing fonts, custom text boxes, unsupported RTF, and Windows project export are pending. | Open and paste an image. Reopen each export in an independent viewer. Import Windows projects from each supported format version and save and reopen the Mac copy. Check dimensions, transparency, annotation order, note text and formatting, mask persistence after Erase All, rejected records, and failed writes. |
| Share, print, and external image editor | In source. Native Print, Share, and a durable working-copy and import workflow use the rendered revision. | Share the composed image, print to a PDF preview and open a working copy in an installed editor. Import changes without overwriting the source. |
| Multiple editors, close all without saving, and recent files | In source. New captures open in separate editors. Close All confirms once. The file menu lists recent images and videos. | Keep an existing snip open while taking a new one, check independent history and current clipboard, then close all with one confirmation. Reopen recent snips and locate recording and screenshot folders. |
| Settings, shortcuts, startup and tray actions | In source. Clipboard, original-save, Fit and Resize preferences can be backed up and restored. Launch at login, menu-bar capture and an opt-in global capture shortcut with six choices use macOS APIs. | Test shortcuts with focus in each editor and dialog. Restart to check settings and ensure unavailable permissions or devices have a clear fallback. |
| Help, original-repo update check, and signed install or upgrade | Partial. The file menu links to Help and checks the original repository for a compatible Mac disk image. The protected signing and notarization workflow is in source. | Install and upgrade the exact Developer ID-signed, notarized DMG on a clean Mac profile. Check Gatekeeper, retained settings and the original repository’s Mac download link. |

## Release verification

- Keep **build**, **signed smoke checks**, and **native interactive checks** in separate records. Match every result to the source revision and disk-image SHA-256.
- Run synthetic checks for OCR reading order and geometry, full-resolution PNG export, stroke history and saved-revision handling from the signed bundle before packaging.
- Use synthetic or sanitized screenshots and recordings on the Mac. Record macOS version, display scaling, permissions and available audio devices with the results.
- Exercise the menu, toolbar and keyboard paths and compare screenshots for each editor state. Verify cancel and failure paths preserve the prior snip and leave the controls usable.
