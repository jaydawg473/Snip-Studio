# Translation source and release provenance

The 0.6.23 candidate includes the local Bergamot/Node runtime, six English/German/Spanish/French model directions, license notices and corresponding-source archives. Keep its entire `translation` directory beside the application. This source checkout excludes runtime executables, WebAssembly, model weights/vocabularies and archives.

The runtime uses official Node 24.22.3, released November 11, 2026. The pinned Windows x64 ZIP SHA256 is `e612af99f626ab415ea225af6bce5c971feb448cb5cae250bb1c3fa50c5f7d9f`; the original executable SHA256 is `86fc4785327db5f5c7558dc6156c543b433c313e813a222e088086222ab4afa6`. Its OpenJS signature and Microsoft timestamp were verified before use. `downloads/node-SHASUMS256.txt` retains the official checksum list. Bergamot and model pins remain unchanged.

This folder retains Snip Studio's `worker.js` bridge, the modified licensed Bergamot `runtime/bergamot/worker/translator-worker.js`, CommonJS metadata, pinned upstream metadata, preparation scripts, the release bundle manifest and license texts. The modified worker handles Windows file URLs and rejects non-file translation fetches. Upstream source locations and hashes are recorded in the manifest and notices.

The `runtime/bundle.json` and notices describe the complete candidate payload. Referenced archives and model files are supplied in that payload, rather than this checkout. They are not claims that those files exist here. Component licenses remain attached to their respective components; no application license grant is added.

These scripts are preparation source, not a fully automatic reproducible release builder. `Prepare-Downloads.ps1` needs PowerShell 7 for parallel downloads; `assemble_payload.py` and `finalize_manifest.py` use Python 3 for maintainer preparation. Assembly also needs the reviewed license/corresponding-source inputs and checked-in worker modifications. Finalization records those inputs only after they are present and reviewed. Use only verified timestamp-signed executable hosts, sign modified scripts before running them, and never execute downloaded PE files until their original publisher signatures and timestamps are verified. The installed offline translator requires neither Python nor PowerShell 7 and performs no model download.

Building the C# application does not assemble or copy a translation runtime. Compilation produces an unsigned staging application that must be signed and verified before execution. For the included translator, use a complete signed candidate/release package. The separately configured LibreTranslate integration requires a trusted compatible server; it is not started by Snip Studio.
